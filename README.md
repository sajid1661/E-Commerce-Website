# E-Commerce Website

This is a full-stack e-commerce website built with modern web technologies. The project includes an admin panel, backend API, and frontend user interface.

## Project Structure

- **admin/**: Admin panel for managing products, orders, and users.
- **backend/**: Server-side API built with Node.js, Express, and MongoDB.
- **frontend/**: User-facing website built with React and Vite.

## Features

- User authentication and registration
- Product catalog with search and filtering
- Shopping cart and checkout
- Order management
- Admin dashboard for inventory and sales

## Technologies Used

- Frontend: React, Vite, Tailwind CSS
- Backend: Node.js, Express.js, MongoDB
- Admin: React, Vite
- Payment: Stripe, Razorpay
- Image Storage: Cloudinary

## Getting Started

1. Clone the repository
2. Install dependencies for each part (admin, backend, frontend)
3. Set up environment variables
4. Run the applications

### Backend Setup

```bash
cd backend
npm install
npm start
```

### Frontend Setup

```bash
cd frontend
npm install
npm run dev
```

### Admin Setup

```bash
cd admin
npm install
npm run dev
```
